# Project Brief: Gekko AI Rebranding

## Overview
Gekko AI (formerly Aura / Aura AI) is an undetectable, stealth-enabled real-time AI interview and exam assistant overlay. It provides real-time speech-to-text transcription via Deepgram, blazing-fast LLM responses via Cerebras, Groq, Gemini, and multi-modal Vision AI capabilities for instant problem solving while remaining invisible to screen captures and proctoring software.

## Primary Objective
Execute a comprehensive, repository-wide rebranding of the application to **"Gekko AI"**:
- Update all documentation, guides, and contribution guidelines (`README.md`, `CONTRIBUTING.md`, `PROCTORING_STEALTH_GUIDE.md`).
- Update all launch scripts, batch scripts, and automation files (`run.bat`, `silent_run.vbs`).
- Update core backend logic, window titles, environment configs, and references (`window_manager.py`, `main.py`, `.env.example`, `.env`, `core/`, `api/`, `services/`).
- Update frontend web assets (`web/index.html`, `web/js/*`, `web/css/*`) including UI brand logos, titles, labels, alt tags, and comments.
- Verify every single file across the repository for brand consistency and ensure no residual references to the legacy name exist where branding applies.
- Validate application functionality, syntax, window title bindings, and hotkey handlers.
