# Product Context: Gekko AI

## Purpose & Value Proposition
Gekko AI is built for candidates facing high-stakes interviews, technical coding challenges (e.g., LeetCode, system design), quantitative assessments, and online exams. 

It provides:
1. **Stealth Operation**: Excluded from screen recordings and proctoring capture via OS-level window display affinities (`WDA_EXCLUDEFROMCAPTURE`), click-through ghost mode, and non-activating window toggles (`SW_SHOWNOACTIVATE`).
2. **Real-Time Intelligence**: Live audio streaming to Deepgram STT, passing contextual prompt memory (candidate resume, target role, company, job description) to ultra-fast inference providers (Cerebras, Groq, Gemini).
3. **Vision AI**: Rapid multi-screenshot capture and OCR/vision analysis without triggering focus changes or tab switches.
4. **Zero Overhead & Cost-Effective**: Bring-your-own-keys (BYOK) model with multi-key rotation and auto-failover across providers.

## User Experience Goals
- **Discretion**: The user must feel completely secure that Gekko AI cannot be detected by interviewers or monitoring tools.
- **Speed**: Sub-second response generation that appears directly in the user's peripheral vision.
- **Minimalist Aesthetics**: Clean, cyberpunk-inspired high-contrast dark theme with customizable transparency and ergonomic hotkey controls.
- **Unified Branding**: A sharp, cohesive identity as **Gekko AI** across UI headers, documentation, onboarding dialogs, and diagnostic pre-flight checks.
